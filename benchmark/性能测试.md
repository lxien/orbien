## TCP 协议带宽测试

1. 新增一个TCP代理

```text
6050(RemotePort)-->5201(LocalPort)
```

2. 运行目标服务

```shell
iperf3 -s -p 5201
```

3. 测试

```shell
iperf3 -c 127.0.0.1 -p 6050   

iperf3 -c 127.0.0.1 -p 6050  -R # 反向测试
```

## HTTP(S)协议代理测试

12线程、400连接、30秒

```shell
wrk -t12 -c400 -d30s --latency http://web.domain.com
```

| 指标                        | 含义                |
|:--------------------------|:------------------|
| Requests/sec              | 吞吐 QPS            |
| Latency Avg / Stdev / Max | 平均、波动、尾延迟         |
| Latency Distribution      | 分位延迟（`--latency`） |
| Non-2xx / Socket errors   | 错误与连接失败           |
