# Orbien 是什么

**Orbien** 是一个开箱即用的隧道与反向代理平台，用于将局域网服务安全暴露到公网，供公网用户访问。

## 功能特性

- **多协议代理**：**TCP** / **UDP** / **HTTP** / **HTTPS** / **SOCKS5** / **文件共享**，内置轻量**NAS**面板
- **多传输协议**：传输层支持**TCP**、**WebSocket**、**QUIC**选型，满足防火墙穿越、弱网等多种场景
- **多路复用**：在同一个TCP物理连接上承载多个逻辑请求，节约资源和降低延迟
- **开发测试**：支持HTTP(S)流量抓包，**原样重放**和**改包后重放**，便于联调与问题复现
- **数据压缩**：内置 **Snappy** / **LZ4** / **Zstd** 多种压缩算法可选
- **安全可控**：隧道 **TLS** / **mTLS** 加密传输、**Token**身份认证、IP / 时间访问控制、**BasicAuth** 认证
- **域名与端口**：自定义域名、子域名；端口池按需分配远程端口
- **高可用能力**：多后端负载均衡与健康检查，降低单点故障影响
- **可视化运维**：内置控制台，支持集中配置、监控与**ACME**证书申请部署续期
