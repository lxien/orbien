Orbien

一个开箱即用的内网穿透与反向代理平台

快速开始下载在线演示GitHub

  • 多协议代理

    支持 TCP / UDP / HTTP / HTTPS / SOCKS5 与文件共享

  • 高性能

    传输层支持 TCP、WebSocket、QUIC协议 零拷贝、多路复用、压缩、限流

  • 安全

    隧道 TLS / mTLS 加密传输，Token身份认证，IP CIDR / 时间窗口访问限制、BasicAuth认证

  • 请求重放

    能捕获 HTTP / HTTPS 请求，支持向上游原样重放、编辑后再重放

  • 域名证书

    集成ACME，通过管理面板实现 TLS 证书签发、部署、续期，内置常见云厂商DNS

  • 负载均衡

    支持 轮询 / 加权 / 随机 / 最少连接负载均衡，健康检查自动摘除故障节点

  • 可视化运维

    内置 Web 管理面板，集中配置管理与指标监控 自带轻量NAS文件面板，支持权限控制

  • 跨平台

    支持 Windows / MacOS / Linux 操作系统 兼容 ARM / X86架构

  • 简单易用

    客户端支持 命令行、配置文件、Spring Boot 嵌入式 使用
